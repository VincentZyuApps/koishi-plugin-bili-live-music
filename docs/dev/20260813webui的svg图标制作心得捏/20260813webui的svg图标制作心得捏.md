# Koishi Console WebUI SVG 图标制作与接入心得

## 结论

Koishi Console 的侧边栏图标不是图片 URL，也不会自动识别任意字符串。正确流程是：制作 Vue SVG 组件，通过 `@koishijs/client` 导出的 `icons.register()` 注册名称，再把名称传给 `ctx.page({ icon })`。

## 推荐目录
```text
client/index.ts
client/page.vue
client/icons/main.vue
client/icons/state-machine.vue
```

## SVG 组件模板
```vue
<template>
  <svg
    class="k-icon"
    viewBox="0 0 24 24"
    xmlns="http://www.w3.org/2000/svg"
    fill="none" stroke="currentColor" stroke-width="1.8"
    stroke-linecap="round" stroke-linejoin="round"
  >
    <circle cx="12" cy="12" r="7" />
    <path d="M9 12h6" />
  </svg>
</template>
```

设计约束：
- 使用 `currentColor`，自动适配亮色、暗色、悬停和选中状态。
- 使用透明背景，不写固定白色或黑色背景。
- 优先单色轮廓或单色填充，避免渐变、阴影和细碎装饰。
- 图标最终通常只有约 24px，应确保缩小后仍能辨认。
- `class="k-icon"` 与 Koishi 自带图标保持一致。
- 建议使用 `24 x 24` 坐标系，描边宽度可从 `1.8` 开始调整。

## 注册并用于页面
```ts
import { Context, icons } from '@koishijs/client'
import MainPage from './page.vue'
import MainIcon from './icons/main.vue'

export default (ctx: Context) => {
  icons.register('activity:my-plugin', MainIcon)

  ctx.page({
    id: 'my-plugin',
    name: '我的页面',
    path: '/my-plugin',
    component: MainPage,
    icon: 'activity:my-plugin',
  })
}
```

图标名称应使用插件命名空间，例如 `activity:my-plugin`，避免与 Koishi 或其他插件重名。

## 多页面必须显式指定唯一 ID

Koishi 默认从 URL 的第一个路径段推导页面 ID。下面两个路径都会得到 `my-plugin`：

```text
/my-plugin
/my-plugin/state-machine
```

如果不写 `id`，后注册的页面会覆盖前一个页面。正确做法是：
```ts
ctx.page({ id: 'my-plugin', path: '/my-plugin', /* ... */ })
ctx.page({ id: 'my-plugin-state-machine', path: '/my-plugin/state-machine', /* ... */ })
```

这与页面内容的 Boolean 开关无关。若页面应始终出现在侧边栏，就始终调用 `ctx.page()`；配置开关只在 Vue 页面内部决定显示正文还是“本页面未开启”的提示。

## 图标空白的常见原因

- `icon: 'music'` 只是字符串，但没有调用 `icons.register('music', component)`。
- 注册名称与 `ctx.page()` 中的名称拼写不一致。
- SVG 使用固定颜色，在当前主题下与背景颜色相同。
- SVG 图形超出 `viewBox`，被边界裁切。
- 两个页面使用了相同 ID，后注册页面覆盖前一个。
- 修改了 `client` 源码，但生产环境仍在读取旧的 `dist`。

## 调整视觉大小

侧边栏会固定 SVG 元素的高度。若图形看起来偏小，不要修改侧边栏布局，优先收紧 `viewBox` 的留白。例如从 `viewBox="0 0 24 24"` 改为 `viewBox="2 2 20 20"`，图形会放大约 20%。收紧前要计算描边范围，为圆角、箭头和声波保留至少半个描边宽度，避免裁切。

## 验证

```powershell
yarn tsc -p external\my-plugin\tsconfig.json --pretty false
yarn build my-plugin
git diff --check
rg -n "activity:my-plugin" external\my-plugin\dist\index.js
```

最后刷新 Koishi Console，分别检查亮色、暗色、悬停、选中、分组菜单和不同缩放比例下的显示效果。
